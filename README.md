# ONSoftware

Public company and product hub for ONSoftware.

## Current live product

- **SellerHQ** — reselling business management at https://sellerhq.onsoftware.uk

## Hub responsibilities

The hub at https://onsoftware.uk provides company information, product discovery, pricing, launch updates, support routing, security information and the canonical public legal documents for ONSoftware and SellerHQ.

## Development

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

The site is a Vite + React + TypeScript application deployed through Vercel.
